# Baccarat Intelligence Console — ローカル版

## 使い方
1. `index.html` をダブルクリックで開く（Safari / Chrome / Edge）。ネット接続不要
2. iPhone: ファイルアプリに `index.html` を置いて開く → 共有 → 「ホーム画面に追加」で全画面アプリとして起動できる
3. データはそのブラウザの localStorage に保存される。別ブラウザ・別端末へは「設定 → JSON を表示 → コピー → インポート」で移行

## 構成
- 単一ファイル（約260KB）。React 18 / htm を同梱、外部通信なし
- フォント（Rajdhani / JetBrains Mono / Noto Sans JP）はオンライン時のみ読込。オフライン時はシステムフォント

## タブ
- ゲーム: 仮想シュー（暗号乱数シャッフル）でプレイ。結果は下記すべてに連動
- 記録: 実テーブル用。B/P/T クイック入力またはカード詳細入力
- 罫線: 大路・珠盤路・大眼仔・小路・甲由路・問路
- 確率: 残りカード組成からの次ハンド確率と期待値
- 予測検証: 6手法の的中率を Wilson 信頼区間つきでランダムと比較
- 判断: 資金ルールによる GO / CAUTION / STOP とセッションレポート
- 設定: シュー・資金・ルール・データ移行・法務同意
